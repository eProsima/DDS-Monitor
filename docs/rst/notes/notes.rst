##############
Version v2.2.0
##############

.. warning::

    This is the last release of the ``2.x`` series.
    This branch has reached its End-of-Life (EOL) and will receive no further releases, bugfixes or security updates.
    Users are encouraged to migrate to the latest stable version of *eProsima Fast DDS Monitor*.

This release includes the following **updates**:

    * Update the project dependencies to their 2.x maintenance branches.
