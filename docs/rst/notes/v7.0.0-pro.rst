###################
Version 7.0.0 |Pro|
###################

This release includes the following **features**:

* Save and load workspaces in offline mode
* Add event timeline charts for live and offline topic values
* Use FastDDS license validation logic
* Add Data Table panes
* Add recording of spied topics to MCAP and SQLite files
* Allowed non-numeric inputs and outputs to custom series
* Refresh the monitor's look and feel
* MCP Server
* Load recent workspaces

This release includes the following **bugfixes**:

* Several general bugfixes, issues and adjustments
* Windows fixes: crashes, debug performance reports, and license warning

This release includes the following **internal changes**:

* Add the shared Claude Code setup for DDS Monitor Pro
* Add a private drive-monitor skill to run, click and capture the monitor on a private X display
