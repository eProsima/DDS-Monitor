#############
Shortcuts Bar
#############

This toolbar exposes shortcuts to buttons with the main functionality to interact with the
*DDS Monitor* application.
These buttons functionality could be seen in the :ref:`edit_menu` and :ref:`view_menu` sections of the
:ref:`application_menu`.

The meaning of each of the icons available in the shortcut bar is explained below:

* |dashboard_layout_1| / |dashboard_layout_2| / |dashboard_layout_3| - A single button that cycles the main
  dashboard layout on each click (Medium, Small, Large, and back to Medium).
  Its icon always shows the layout currently applied.
* |historical_chart| - Display historical data.
* |dynamic_chart| - Display real-time data.
* |create_alert| - Open the *Add alert* dialog.
* |refresh| - Refresh DDS Monitor.
* |clear_log| - Clear the list of logs.
* |clear_issues| - Clear the issues panel.

By default, only the *Dashboard Layout*, *Display Real-Time Data* and *Refresh* buttons are shown.
The *Display Historical Data*, *Create Alert*, *Clear Log* and *Clear Issues* buttons are hidden by default and can
be enabled from *View->Customize Shortcuts Toolbar*.

This bar can be hidden (or revealed in case it is already hidden) from the menu *View->Hide/Show Shortcuts Toolbar*.
It is also possible to configure the shortcuts displayed from *View->Customize Shortcuts Toolbar*.
