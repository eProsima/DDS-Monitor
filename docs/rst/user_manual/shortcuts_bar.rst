#############
Shortcuts Bar
#############

This toolbar has shortcut buttons for the main *DDS Monitor* actions.
The same actions are described in the :ref:`edit_menu` and :ref:`view_menu` sections of the
:ref:`application_menu`.

The icons in the shortcut bar are:

* |dashboard_layout_1| / |dashboard_layout_2| / |dashboard_layout_3| - A single button that cycles the main
  dashboard layout on each click (Medium, Small, Large, and back to Medium).
  Its icon always shows the layout currently applied.
* |historical_chart| - Display historical data.
* |dynamic_chart| - Display real-time data.
* |create_alert| - Open the *Add alert* dialog.
* |refresh| - Refresh DDS Monitor.
* |clear_log| - Clear the list of logs.
* |clear_issues| - Clear the issues panel.

By default, only the *Dashboard Layout*, *Display Real-Time Data* and *Refresh* buttons are shown.
The *Display Historical Data*, *Create Alert*, *Clear Log* and *Clear Issues* buttons are hidden by default.
You can enable them, or change which shortcuts are shown, from *View->Customize Shortcuts Toolbar*.

To hide or show this bar, use *View->Hide/Show Shortcuts Toolbar*.
