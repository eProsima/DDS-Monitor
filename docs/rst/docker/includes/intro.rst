The eProsima Fast DDS Suite Docker image is a quick demonstration of Fast DDS running on an Ubuntu
platform. Download it from `eProsima's downloads page <https://eprosima.com/index.php/downloads-all>`_,
under eProsima Fast DDS. For the chosen FastDDS version, the file is named
``ubuntu-fastdds-suite <FastDDS-Version>.tar``.

This Docker image was built for Ubuntu 22.04 (Jammy Jellyfish).

To run this container you need Docker installed. From a terminal run:

.. code-block:: bash

    $ sudo apt install docker.io
