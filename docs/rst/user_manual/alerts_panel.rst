.. _alerts_panel:

############
Alerts Panel
############

The alerts panel is on the left side of the application window and has two sections:

.. _alerts_list_panel:

Alert List
==========

This panel lists the alerts you have created. Each alert watches the conditions defined for it.
A selected alert is highlighted, and its details appear in the :ref:`alert_info_panel`.

.. _alert_info_panel:

Info
====

This panel shows the information of the currently **selected** alert.
